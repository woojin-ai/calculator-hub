### — 유튜브 「전설들의 매매법」 35개 스크립트 분석 기반, 코스피/코스닥 자동매매용 —

> 작성일: 2026-07-26
> 목적: 키움증권 OpenAPI+ 또는 한국투자증권(KIS) REST API 기반 자동매매 봇의 전략 명세

## 0. 스크립트 분석 결과 요약

### 0-1. 소스에 대한 냉정한 평가 (반드시 읽을 것)

35개 영상은 전부 동일 포맷이다:

1. 해외 트레이더의 극적인 스토리 (110만원→3억, 1년에 100억 등)
2. "승률 99.9x%, 수익률 xxx%" 백테스트 주장 — **검증 불가, 사실상 허구**
3. 트레이딩뷰에서 이미 결과를 아는 과거 차트로 시연 (생존편향 + 후행 선택)
4. "지표 무료 공유" → 개인 전화번호 문자 / 링크에 "8번" 입력 유도 → **리드 수집이 목적**

따라서 **"이 지표만 있으면 승률 99%"라는 프레임은 전부 버린다.**
대신 35개 영상이 반복적으로 재포장하고 있는 **기저 기법**은 업계 표준 기법이며, 이것만 추출한다.

### 0-2. 추출된 핵심 기법 (등장 빈도순)

| # | 기법 | 출처 영상(트레이더) | 한국 적용성 |
|---|------|-----------------|-----------|
| 1 | **신호 후 즉시 진입 금지 → 눌림(되돌림) 확인 후 진입** ("확인→반응→진입") | 제이슨 노아(리듬 매매), 리라즈 조시(0.5 피보나치 되돌림), 캐스퍼 SMC(FVG 되돌림) | ★★★ 전략의 심장 |

| 3 | **오프닝 레인지 기준선**: 장 시작 첫 15분(또는 5분) 캔들 고가/저가에 선을 긋고 돌파 방향으로만 매매 | 캐스퍼 SMC(뉴욕장 9:30 첫 캔들) | ★★★ 한국 9:00 개장에 직결 |

| 6 | **멀티 타임프레임 확인**: 보는 봉의 3~4배 상위 봉으로 신호 진위 확인 (5분봉 신호 → 15분봉 RSI 재확인) | 래리 윌리엄스(월드컵 챔피언십 11,000%) | ★★★ 필터로 채택 |
| 7 | **지지저항 + 플립**: 거래량 집중 구간이 진짜 지지저항. 저항 돌파 후 되돌림 리테스트가 최고의 롱 타점. 같은 지지선을 여러 번 시험하면 힘이 빠진 것 | 알렉스 곤잘레스, 톰 크라운 | ★★★ 눌림 타점 정의에 사용 |
| 8 | **세력의 흔들기(유동성 사냥)**: 명백한 지지선 살짝 이탈 → 개미 손절 유발 → 급반등. 이탈 직후 추격하지 말고 "스윕 후 회복"을 확인 | 마크 틸버리(SMC), 루이스 캘리(뉴 스마트머니) | ★★☆ 손절 버퍼 설계에 반영 |
| 9 | **추세 필터 (밴드/슈퍼트렌드/추세선)**: 추세 방향으로만, 신호 소멸 시 전량 청산 | 와카르(뉴 슈퍼트렌드), 자레드 웨슬리, 크리스토퍼(13 EMA+ATR 라인), 로스 카메론(트렌드라인) | ★★☆ 청산 로직에 반영 |

| 11 | **과매수/과매도 역추세 매매의 결함**: RSI 30/70 단독 역추세는 틀린다. 상위 TF 동조 시에만 유효 | 래리 윌리엄스, 가브리엘 레이바 | ★★☆ 역추세 진입 자체를 배제 |
| 12 | **작은 수익 누적 철학**: 한 번에 10%가 아니라 1~3%씩 수십 번. "이긴 전쟁에서 전리품을 더 탐할 때가 가장 위험하다" | 에단 갈렌드, 제이슨 노아(하루 40회), 데이비드 폴 | ★★★ 운영 철학 |

| 14 | FVG(Fair Value Gap) | 캐스퍼 SMC | ★★☆ 1분봉 갭은 한국 소형주에서 빈번·무의미해 "돌파 레그의 되돌림 존"으로 일반화 채택 |

### 0-3. 해외 기법 → 한국 시장 번역표

| 해외 개념 (스크립트) | 한국 시장 대응 |
|---|---|
| 뉴욕장 9:30 오픈 첫 캔들 | **KRX 09:00 개장. 08:30~09:00 동시호가 → 09:00 시가.** 첫 5/15분 캔들이 기준선 |
| 롱/숏 양방향 | **개인 개별주 공매도 사실상 불가 → 롱 온리.** 숏 신호는 "청산/관망 신호"로만 사용 |
| 볼륨 델타 (매수/매도 체결 분리) | **체결강도** = (매수체결량 ÷ 매도체결량) × 100. 양 API 모두 실시간 제공. 120~130↑ = 매수 우위 |
| 레버리지 3~10배 | 현물 기본. (미수/신용은 전략 검증 후에도 비권장) |
| 24시간 크립토 변동성 | 09:00~09:30에 하루 변동성의 30~50% 집중. **시간 필터가 곧 변동성 필터** |
| 세력/고래 스탑 헌팅 | 동일하게 존재 (호가 얇은 코스닥에서 더 심함) → 손절선에 ATR 버퍼 필수 |
| 없음 | **VI(변동성완화장치)**: 동적 2~3%/정적 10% 급변 시 2분 단일가 → 봇이 반드시 처리해야 할 한국 고유 이벤트 |
| 없음 | **가격제한폭 ±30%**, 상한가 잠김(점상) 시 매도 불가 리스크 |
| 수수료만 | **매도 시 거래세+농특세 ~0.15~0.18% + 수수료 + 슬리피지 → 왕복 실비용 약 0.25~0.4%.** 기대수익 1% 미만 셋업은 전부 스킵해야 하는 이유 |

## 1. 전략 개요 — "K-ORB 눌림목" (Korea Opening Range Breakout + Pullback)

**한 문장 요약:**
> 갭·거래대금·체결강도로 추린 5~15개 종목을 감시하다, 09:15 기준선(오프닝 레인지 고가)을 **대량 거래량과 함께 돌파**한 종목이 **얕게 눌린 뒤 재상승하는 첫 캔들**에서만 매수하고, 1.5R에서 절반 익절 후 추세 소멸까지 끌고 간다. 신규 진입은 오전에만.

3단계 구조 (제이슨 노아의 "확인 → 반응 → 진입" 그대로):

```
[확인]  기준선 돌파 + 거래량 폭증 + 체결강도 우위     → 아직 사지 않는다
[반응]  얕은 눌림 (돌파 레그의 38~62% 되돌림, 거래량 감소) → 아직 사지 않는다
[진입]  눌림 후 직전 1분봉 고가를 다시 상향 돌파하는 첫 캔들 → 이때만 산다
```

돌파 캔들 추격 매수를 구조적으로 금지하는 것이 이 전략의 정체성이다. (35개 영상 중 가장 많이 반복된 단 하나의 교훈: "신호가 떴다고 바로 들어가지 마라.")

## 2. Phase 0 — 장전 유니버스 필터링 (08:00 ~ 08:59)

### 2-1. 전일 데이터 기반 1차 필터 (08:00 실행)

| 조건 | 값 (초기값, 백테스트로 튜닝) | 근거 |
|---|---|---|
| 시장 | 코스피 + 코스닥 보통주 | ETF/ETN/스팩/우선주/리츠 제외 |
| 상태 | 관리종목·투자경고·투자위험·거래정지·단기과열 제외 | API 종목상태 코드로 필터 |
| 주가 | 2,000원 ~ 200,000원 | 저가주 슬리피지·상폐리스크, 고가주 호가단위 비효율 회피 |
| 시가총액 | 800억 ~ 5조 | 너무 작으면 세력 놀음, 너무 크면 단타 변동성 부족 |
| 전일 거래대금 | ≥ 300억 | 유동성 하한. 이보다 작으면 내 주문이 시장을 움직임 |
| 전일 등락 | -5% ~ +25% | 전일 상한가 직행 종목은 갭 과열 위험 |

### 2-2. 동시호가 기반 2차 필터 (08:40 ~ 08:59, 예상체결가 폴링)

| 조건 | 값 | 근거 (스크립트 매핑) |
|---|---|---|
| **예상 갭** | **+3% ~ +10%** | 갭이 곧 "유동성이 몰리는 시간"(캐스퍼의 뉴욕 오픈 조건의 한국판). +10% 초과 갭은 이미 재료 소진+VI 직행 위험 |
| 예상체결 수량 | 전일 총거래량의 3%↑ | 개장 전부터 관심 집중 확인 |
| 뉴스/공시 체크 | 유상증자·CB발행·소송 등 악재 공시 시 제외 | API 공시 조회 or 뉴스 크롤링 |
| 최종 감시 종목 수 | **5 ~ 15개** (갭×예상거래대금 스코어 상위) | 1분봉 실시간 처리 가능한 수준으로 제한 |

> 구현: 키움 조건검색식(장전 예상체결 조건) 또는 KIS 예상체결 API 폴링. 08:59에 워치리스트 확정 후 실시간 체결/호가 WebSocket 구독 시작.

## 3. Phase 1 — 오프닝 레인지 설정 (09:00 ~ 09:15)

**이 15분 동안은 절대 매매하지 않는다.** (개장 직후 5분은 스프레드·변동성 최악 + VI 빈발. 자레드 "가장 컨디션 좋은 타이밍만 골라라"의 구현)

각 감시 종목에 대해 기록:

- `OR_High` = 09:00~09:15 고가 (기준선. 캐스퍼의 "첫 15분봉 고가"와 동일)
- `OR_Low` = 09:00~09:15 저가
- `OR_Range` = OR_High − OR_Low
- `VWAP` 계산 시작 (당일 누적)
- `RVOL` = 첫 15분 거래량 ÷ 최근 20일 동시간대 평균 거래량
- 1분봉 ATR(14) 계산 시작

### 15분 시점 탈락 조건 (플랫존 필터 — 이드리스의 "횡보구간 매매 금지"의 구현)

- `OR_Range < 1.2 × ATR(일봉,14) × 0.15` → 변동성 죽은 종목, 감시 해제
- 첫 15분 `RVOL < 3.0` → 관심 소멸, 감시 해제
- 시가 대비 -3% 이하로 하락 중 → 갭 하락 반전 실패, 감시 해제
- 첫 15분 내 하락 VI 발동 → 감시 해제

## 4. Phase 2 — 진입 로직 (09:15 ~ 11:00, 신규 진입 허용 창)

종목별 상태머신: `WATCH → BREAKOUT → PULLBACK → ARMED → POSITION` (어긋나면 `WATCH`로 복귀)

### 4-1. [확인] 돌파 감지 (WATCH → BREAKOUT)

1분봉 마감 기준으로 **모두** 충족:

| 조건 | 값 | 스크립트 근거 |
|---|---|---|
| B1. 종가가 `OR_High` 위에서 마감 | 종가 > OR_High (꼬리 터치 무효 — **몸통 돌파**) | 캐스퍼 "몸통 돌파" 명시 |
| B2. 돌파 분봉 거래량 | ≥ 직전 20개 1분봉 평균의 **3배** | 리라즈 "기준선 위로 올라온 거래량만 유효" |
| B3. 체결강도 | ≥ **130** (돌파 시점 스냅샷) | 데이비드 폴 볼륨 델타의 한국판. 매수 체결이 주도했는지 확인 |
| B4. 15분봉 필터 | 15분봉 종가 > 15분봉 EMA(20), RSI(14,15분) < **75** | 래리 윌리엄스 멀티 TF: 상위 봉이 이미 과열이면 돌파가 꼭짓점일 확률↑ |
| B5. VWAP 필터 | 현재가 > VWAP | 기관/세력 평단 위 = 매수 우위 구간 |
| B6. VI 필터 | 직전 5분 내 VI 발동 이력 없음 | VI 직후 재개장 첫 분봉은 노이즈 |

→ 충족 시 `BREAKOUT` 상태 진입, `Leg_Low`(돌파 시작 저점), `Leg_High`(돌파 후 최고가) 추적 시작. **여기서 매수하지 않는다.**

### 4-2. [반응] 눌림 감지 (BREAKOUT → PULLBACK → ARMED)

돌파 후 **3~12분 이내**에 다음을 충족하는 되돌림 발생:

| 조건 | 값 | 스크립트 근거 |
|---|---|---|
| P1. 되돌림 깊이 | 돌파 레그(Leg_Low→Leg_High)의 **38% ~ 62%** 구간 진입 (중심 50%) | 리라즈 "0.5 피보나치 되돌림 진입" |
| P2. 또는 기준선 리테스트 | 저가가 OR_High의 ±0.3% 이내 터치 | 알렉스 "저항→지지 플립 리테스트" |
| P3. 눌림 거래량 | 눌림 분봉들 평균 거래량 < 돌파 분봉 거래량의 50% | "매도세가 약한 눌림"만 유효 (거래량 실린 하락 = 분산) |
| P4. 이탈 무효 조건 | 눌림 저가가 Leg_Low 또는 VWAP−0.5×ATR(1분) 하회 시 | 되돌림이 아니라 추세 붕괴 → `WATCH` 복귀 |
| P5. 시간 초과 | 돌파 후 12분 내 P1/P2 미발생 → `WATCH` 복귀 | 리듬 소멸 (제이슨 노아 "리듬이 끊기면 버려라") |

P1~P3 충족 시 `ARMED` 상태. `PB_Low`(눌림 저점) 기록.

### 4-3. [진입] 트리거 (ARMED → POSITION)

- **T1. 1분봉 종가가 직전 1분봉 고가를 상향 돌파하며 마감** (눌림 후 첫 반등 확정 캔들 — 제이슨 노아 "눌렸다가 다시 반등하는 그 첫 캔들")
- T2. 그 반등 분봉의 체결강도 ≥ 110
- T3. 호가 스프레드 ≤ 0.3% (얇은 호가 진입 금지)
- T4. **예상 손절폭 검증**: (진입가 − 손절가) ÷ 진입가 ≤ **1.5%** 초과 시 진입 포기 (손익비 확보 불가)

**주문 집행:**
- 최우선매도호가 지정가 IOC(모의: 시장가). 미체결 잔량은 즉시 취소 후 1회만 재시도
- 체결 실패 2회 → 해당 셋업 포기 (추격 금지)

### 4-4. 포지션 사이징 (자금 관리)

```
R (1회 허용 손실) = 계좌 평가액 × 0.5%
주문 수량 = floor( R ÷ (진입가 − 손절가) )
단, 종목당 최대 투입금 = 계좌의 20% (체결 유동성 고려해 추가로 최근 1분 평균 거래대금의 3% 이내)
```

## 5. Phase 3 — 청산 로직 (매도 규칙)

### 5-1. 초기 손절 (Stop Loss)

```
SL = min( PB_Low − 0.3 × ATR(1분,14),  OR_High × 0.995 )
```
- `PB_Low` 바로 아래가 아니라 **ATR 버퍼**를 둔다 — 세력 흔들기(스탑 헌팅)로 저점 살짝 깨고 반등하는 패턴(마크 틸버리 편에서 반복 등장) 회피
- 손절은 **서버 등록 스탑주문이 아닌 봇 감시 후 시장가 발사** (한국 API는 조건부주문 제약이 많음). 단, 봇 다운 대비 데드맨 스위치 필수 (§8)

### 5-2. 익절 시퀀스 (전 영상 공통 "50% → 트레일 → 신호소멸 전량" 구조)

| 단계 | 조건 | 행동 |
|---|---|---|
| TP1 | 수익 = **+1.5R** 도달 | **50% 매도**, 손절선을 진입가(본절)로 상향 |
| TP2 | 수익 = **+2.5R** 도달 | **추가 25% 매도** |
| 트레일 | TP1 이후 | 손절선을 `직전 3분봉 저가 − 0.2×ATR`로 계속 상향 (크리스토퍼 "라인이 끊기면 전량"의 구현) |
| 전량 청산 A | 3분봉 종가가 VWAP 하회 마감 | 잔량 전량 시장가 |
| 전량 청산 B | 체결강도 100 미만으로 급락 + 대량 음봉(평균 3배 거래량) | 잔량 전량 시장가 (볼륨 델타 반전 = 세력 이탈) |
| 전량 청산 C | 15:00까지 보유 중 | **14:55 무조건 전량 청산. 오버나잇 금지** |

### 5-3. VI(변동성완화장치) 대응 — 한국 고유 로직

| 상황 | 대응 |
|---|---|
| **보유 중 상승 VI 발동** | 주문 불가 2분. 재개 단일가가 VI 발동가 대비 +1% 이상 → 홀드 지속 / 미만 → 재개 직후 TP 규칙 무관 50% 매도 (VI 후 되밀림 방어) |
| 보유 중 하락 VI 발동 | 재개 즉시 전량 시장가 청산 (손절 원칙 우선) |
| 미보유 종목이 VI 후 급등 재개 | **추격 진입 금지.** 상태머신 리셋 후 새 눌림 형성 시에만 재고려 |
| 상한가 잠김 | 잔량 홀드, 14:55 규칙만 유지. 다음날 갭 매도 로직은 v2에서 |

### 5-4. 일일 서킷브레이커 (계좌 보호 — "감정 구간" 차단의 자동화)

- 당일 실현손실 ≥ 계좌의 **-1.5%** → **당일 봇 정지**
- 연속 손절 3회 → 당일 정지 (제이슨 노아 "수익/손실 직후가 가장 위험한 감정 구간")
- 동일 종목 재진입: 손절 후 **1회만** 허용, 그것도 새 셋업(돌파부터 다시) 성립 시
- 하루 최대 신규 진입: **5회**

핵심 구현 노트:

1. **1분봉은 체결 틱에서 직접 집계**한다 (API 분봉 조회는 지연·누락 있음). 봉 마감 판정은 거래소 체결시각 기준.
2. **체결강도**는 KIS 실시간 체결 데이터의 체결강도 필드 사용. 돌파 판정 시 "그 분봉 구간의" 스냅샷을 저장할 것 (누적치와 혼동 금지).
3. 모든 상태 전이·주문·체결에 타임스탬프 로그 → 이 로그가 그대로 백테스트 검증 데이터가 된다.
4. **데드맨 스위치**: 봇 프로세스가 30초 무응답이면 별도 워치독 프로세스가 전 종목 시장가 청산 + 텔레그램/푸시 알림.
5. 주문 API 호출 제한(초당 건수) 준수 — 큐 기반 스로틀링.

### 7-3. 상태머신 의사코드

```python
class StockFSM:
    def on_minute_close(self, bar, snap):  # snap: 체결강도, VWAP, 호가
        if self.state == WATCH:
            if (bar.close > self.or_high and
                bar.volume >= 3 * self.avg_vol_20 and
                snap.cheGang >= 130 and
                self.tf15_ok() and bar.close > snap.vwap and
                not self.recent_vi(min=5)):
                self.leg_low, self.leg_high = self.recent_swing_low(), bar.high
                self.state, self.t_break = BREAKOUT, bar.t

        elif self.state == BREAKOUT:
            self.leg_high = max(self.leg_high, bar.high)
            if bar.t - self.t_break > 12*MIN: self.reset(); return
            fib = self.leg_high - (self.leg_high - self.leg_low) * 0.5
            zone_lo = self.leg_high - (self.leg_high - self.leg_low) * 0.62
            in_fib  = zone_lo <= bar.low <= self.leg_high - (self.leg_high-self.leg_low)*0.38
            on_line = abs(bar.low - self.or_high) / self.or_high <= 0.003
            weak_pb = bar.volume < 0.5 * self.break_vol
            broke   = bar.low < self.leg_low or bar.close < snap.vwap - 0.5*self.atr1m
            if broke: self.reset(); return
            if (in_fib or on_line) and weak_pb:
                self.pb_low, self.state = min(bar.low, getattr(self,'pb_low',1e12)), ARMED

        elif self.state == ARMED:
            if bar.low < self.pb_low - 0.3*self.atr1m: self.reset(); return
            if (bar.close > self.prev_bar.high and snap.cheGang >= 110
                and snap.spread_pct <= 0.003):
                sl = min(self.pb_low - 0.3*self.atr1m, self.or_high*0.995)
                if (bar.close - sl)/bar.close <= 0.015:
                    self.enter(price=bar.close, stop=sl)   # → POSITION
                else:
                    self.reset()

        elif self.state == POSITION:
            self.manage_exit(bar, snap)  # §5 규칙
```

## 8. 검증 로드맵 (실계좌 투입 전 필수 관문)

| 단계 | 내용 | 통과 기준 |
|---|---|---|
| 1. 데이터 수집 | KIS로 과거 1분봉 + 일봉 수집 (최소 2년). 체결강도 과거치는 없으므로 실시간 수집을 지금부터 병행 축적 | 갭 상위 종목 일별 20개 × 2년 분봉 확보 |
| 2. 백테스트 | 수수료 0.015%×2 + 거래세 0.18% + 슬리피지 1호가 반영. 파라미터 워크포워드 | **비용 반영 후** 프로핏 팩터 ≥ 1.3, MDD ≤ 15% |
| 3. 모의투자 | KIS 모의계좌로 실시간 4주 | 백테스트 대비 성과 괴리 ≤ 30% |
| 4. 실계좌 소액 | 리스크 0.25%로 축소, 4주 | 슬리피지 실측치가 가정 이내 |
| 5. 정상 운영 | 리스크 0.5% 복귀 | 월간 리뷰로 파라미터 드리프트 점검 |

### 현실적인 기대치 (영상의 환상 교정)

- 영상들이 주장하는 승률 99%는 존재하지 않는다. 이런 눌림목 돌파 전략의 현실적 목표는 **승률 40~55% × 평균 손익비 1.5~2.0** — 이것만으로도 기대값은 양수다.
- 손익분기 승률 = 1/(1+손익비). 손익비 1.5면 승률 40%만 넘으면 된다. **전략의 생명은 승률이 아니라 손절 규칙의 기계적 집행이다** (이건 영상들도 공통적으로 맞게 말한 부분).
- 갭 상승 모멘텀 전략은 시장 국면 의존성이 크다. 지수 급락장·테마 소멸기에는 셋업 자체가 안 나온다 — 매매 없는 날이 정상이며, 억지로 낮춘 필터로 매매를 만들어내는 순간 죽는다.
- 자동매매의 실제 사망 원인 1위는 전략이 아니라 **운영사고**(토큰 만료, WebSocket 끊김, 중복 주문, 봉 집계 버그)다. §7-2의 로깅·워치독이 전략 코드보다 중요하다.
