# excelexercises.com 해부 + 우리식 제작안 (2026-11-25)

출처 영상: 메타뷰 「운영비 19만 원에 월 4,900만 원…」(원본 Starter Story, 창업자 Jake Shimota)
⚠ 자막에 나온 `excelexercise.com`(s 없음)은 **엉뚱한 광고 도메인으로 튕김**. 진짜는 `excelexercises.com`.

## 1. 실제로 확인한 것 (사이트 직접 열어 본 사실)

| 항목 | 내용 |
|---|---|
| 호스팅 | Firebase Hosting (없는 주소 → Firebase 기본 404 페이지) |
| 화면 | 손으로 짠 정적 HTML + jQuery 3.2.1 + Bootstrap. 프레임워크·빌드 없음 |
| 로그인·DB | Firebase 8 (auth, firestore, functions) |
| 결제 | Stripe. `customers/{uid}/subscriptions`, `.../payments` 구조 = Firebase 공식 "Stripe 결제 확장" 형태로 추정 |
| 요금 | 월 $19.99 / 연 $59.99(월 $4.99꼴, "75% 할인" 표시) / 평생 $199 |
| 무료 범위 | `numberOfFreeLessons = 2` → 레슨 2개만 무료, 그다음 결제 벽 |
| 문제 저장 | Firestore `problemSets/ps{번호}/screens/screen{번호}` 문서 하나 = 화면 하나 |
| 문제 종류 | `type` 필드: `f`(수식 입력), `h`(단축키 누르고 있기), 그 외 p·e 등 |
| 정답 판정 | **수식을 계산하지 않음.** 입력을 소문자로 바꾸고 공백·둥근따옴표 정리 → 허용 답 목록(`solution`)과 글자 비교 |
| 단축키 판정 | 키를 하나씩 눌러 `acceptedAnswers[순서]`와 맞추고, 맞을 때마다 키보드 그림 교체 |
| 표 | 처음엔 직접 만든 `<table>` 조작(`tableManipulations.js`, 75KB). 지금은 **Univer 0.25.1**(오픈소스 시트 엔진) 격자를 문제마다 켜는 실험 중 (`?univer=1`) |
| 틀렸을 때 | `incorrectAnswers` 컬렉션에 오답 기록 → 어디서 막히는지 데이터로 봄 |
| 게임 요소 | 점수(정답 15점), 연속 학습일(streak), 순위표(`scores`, `streaks`), 수료증(LinkedIn) |
| 단체 판매 | 학교·회사 **이메일 도메인 목록**을 코드에 박아 두고 해당 도메인이면 무료 프리미엄 처리 |
| 콘텐츠 | 사이트맵 180개: 연습 86 + 함수 설명글 42 + SQL 연습 23 + 레슨 묶음 페이지 |
| 홈 화면 | 본문 약 1,200단어, H2 9개("지루한 동영상 문제를 푼다" 등) — 영상 속 "홈 2,000단어 글" 전략 그대로 |
| 추적 | GA4, GTM, 메타 픽셀, 빙 UET, MS Clarity, 구글 광고 전환 — 광고 돌리는 중 |

## 2. 이 사이트에서 배울 점과 피할 점

**배울 점**
1. 기술은 단순해도 됨. 핵심은 "격자에 직접 쳐 본다"는 손맛 하나.
2. 문제를 DB 문서로 분리 → 코드 수정 없이 문제 추가.
3. 오답을 다 모아서 다음 문제·설명 고치는 데 씀.
4. 무료 2개 → 바로 결제 벽. 월 요금을 비싸게 두고 연간 결제로 몰아줌(월 $19.99 vs 연 환산 $4.99).
5. 함수 설명글(SEO) 42개가 연습 페이지로 이어지는 구조.

**피할 점 (그대로 베끼면 안 되는 곳)**
1. 프리미엄 여부를 **브라우저 코드에서** 판단함. 무료 이메일·도메인 목록이 공개 JS에 그대로 노출되고, 부분 글자 비교라 허술함 → 우리는 서버(보안 규칙·API)에서 판정.
2. 정답을 글자 비교로만 봄 → `=SUM(A1:A5)`와 `=SUM(A1,A2,A3,A4,A5)`처럼 맞는 다른 답이 오답 처리될 수 있음 → 우리는 계산 결과로 판정.
3. 정답 목록이 브라우저로 내려옴 → 개발자도구로 보임. 유료 문제는 서버에서 채점.

## 3. 우리식 제작안 (한국판)

**주제 각:** 그냥 "엑셀 연습"보다 **컴활(컴퓨터활용능력) 2급·1급 실기 함수 연습**이 한국 검색 수요가 큼. 직장인 실무 함수(VLOOKUP/XLOOKUP, SUMIFS, 피벗)는 2단계.

**스택 (돈 안 드는 쪽)**
- 화면: Next.js (지금 계산기 허브와 같은 방식) + Vercel 무료
- 격자: Univer (Apache-2.0, 무료) — 원조도 이걸로 옮겨 가는 중
- 수식 계산: Univer 내장 계산기 또는 `fast-formula-parser`(MIT). ⚠ HyperFormula는 GPL/유료 라이선스라 피함
- 문제 데이터: 처음엔 레포 안 JSON 파일(무료, 버전 관리). 회원·진도는 2단계에서 Supabase 무료 등급
- 채점: 무료 문제는 브라우저 채점, 유료 문제는 서버 함수에서 채점
- 결제: 3단계. 토스페이먼츠 등은 월정액은 없고 건당 수수료라 **결제 붙이기 전 사용자 확인 필요**

**단계**
1. **MVP (1~2주):** 문제 20개(SUM·COUNT·IF·VLOOKUP 기초) + 격자 + 결과값 채점 + 오답 힌트. 로그인 없이 진도는 브라우저 저장. 계산기 허브에 "엑셀 연습" 메뉴로 붙여서 기존 유입 활용.
2. **SEO:** 함수별 설명글(한국어) 1개 = 연습 문제 링크 1개. 홈은 "왜 영상보다 직접 치는 게 빠른가" 긴 글.
3. **회원·게임:** 로그인, 연속 학습일, 순위표, 수료증.
4. **수익화:** 무료 2~3레슨 후 결제 벽 또는 광고(애드센스). 학교·회사 단체 판매는 그다음.

## 3-1. MVP 구현 (2026-11-25)
- 주소: `/excel`(레슨 목록), `/excel/[slug]`(레슨 5개 × 문제 4개 = 20문제). 헤더 메뉴 "엑셀", 홈 하단 카드, 사이트맵 추가.
- 수식 엔진: `lib/excel/formula.ts` (외부 라이브러리 없이 직접 작성, 함수 40여 개). Univer는 무거워서 MVP에선 안 씀.
- 채점: `lib/excel/grade.ts` — 결과값 비교 + 변형 표(숫자 크기 변경·칸 하나씩 극단값·범위 안 행 돌리기)로 "우연히 맞은 답"·"답 숫자 직접 입력"을 거름.
- 진도: 브라우저 localStorage에만 저장(`lib/excel/progress.ts`).
- 테스트: `npx tsx scripts/regression/excel.test.ts` (188개).

## 4. 확인 못 한 것
- REA CLI는 이 PC Node 24.12.0이 요구 버전(24.22.1+)보다 낮아 실행 실패 → 같은 내용을 직접 코드 읽기로 확인함.
- 로그인 뒤 화면(대시보드·순위표)과 유료 문제는 결제가 필요해 보지 않음.
- 매출·구독자 수는 영상 속 본인 발언 기준이며 검증 불가.
