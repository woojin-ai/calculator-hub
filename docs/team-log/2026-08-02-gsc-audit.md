## 2. 🔴 어제 P0 반증 — `*.vercel.app`은 애드센스 규정상 적격이다

마케팅팀이 1차 출처로 어제 자기 팀의 진단을 뒤집었다. 사용자에게 **돈을 쓰게 하는 항목**이라 최우선으로 기록한다.

| 근거 | 내용 |
| --- | --- |
| 애드센스 공식(answer/12170421) | 사이트 추가 가능 대상에 **"Public Suffix List에 이미 등재된 플랫폼의 서브도메인(예: `site.appspot.com`)"** 명시 |
| Vercel 공식 KB | **`vercel.app`은 Public Suffix List 등재 도메인**이다 |

→ 구글이 예시로 든 `site.appspot.com`과 우리 `calculator-hub-delta.vercel.app`은 **애드센스 규정상 같은 등급의 적격 사이트**다. "서브도메인이라 자동 필터에 걸렸다"는 형태의 가설은 이 문서로 **배제된다.** 어제 §10이 스스로 든 반대 증거(ads.txt 별도 승인 = 소유권 검증 통과)와도 일관된다.

**판정: P0 → P3 강등.** 커스텀 도메인은 브랜딩·URL 이전 비용 측면의 독립적 가치가 있으므로 "사면 좋다"는 유지하되, **"애드센스 거절 원인"이라는 명분은 철회한다.**

**한계 명시**: PSL 등재 = "사이트로 추가 가능"이지 "품질 심사 통과 보장"이 아니다. 반증된 것은 *원인 가설*이지 도메인의 가치가 아니다.

### 2-1. "가치가 낮은 콘텐츠"의 공식 정의는 우리 상황과 무관하다

구글 게시자 정책 용어집의 축자 정의는 **"사용자에게 가치가 없는 이해 불가 콘텐츠(예: 채우기 텍스트, lorem ipsum)"** 다. 우리 사이트는 여기 해당하지 않는다. **거절 메일의 라벨과 정책 용어집의 정의가 같은 단어인데 다른 것을 가리킨다.**

→ **우리는 판정 기준이 공개되지 않은 결정에 대해 원인을 추측하고 있다.** 어떤 팀이 무슨 원인을 대든 그건 추론이며, "이걸 고치면 통과한다"고 말할 수 있는 근거는 누구에게도 없다. 이 문장을 다음 실행이 반드시 이어받아야 한다.

실제로 문서화된 요건은 이것뿐이다: **"충분한 고유 콘텐츠(enough unique content)"**, **"고품질·독창적"**, "좋은 사용자 경험". **"표(table)"·"이미지"라는 단어는 애드센스 정책 전문에 0회 등장한다.**

## 3. ★결함 확증 — 그리고 범위가 티켓보다 컸다

어제 티켓은 "`BlogSection`에 image·table 타입 부재"였다. 오늘 라이브 실측으로 전제를 확증했고, **더 나쁜 사실**을 찾았다.

| 실측 | 값 |
| --- | --- |
| 블로그 상세 36장 `<table>` | **0개** |
| 블로그 상세 `<article>` 내 `<img>` | **0장** |
| 계산기 16장 `<table>` | **0개** |
| **본문 산문이 "표"라고 지칭하는 지점** | **22곳** (`"표를 세로로 훑어보면"`, `"위 표에서"`, `"표를 보면"` 등) |

**즉 저자는 표를 의도했는데 타입이 없어 불릿 리스트로 대체했고, 산문은 표를 가리키는 채로 발행됐다.** 독자는 "표를 세로로 훑어보면"을 읽고 불릿 목록을 본다.

**이것이 오늘 작업의 정당한 명분이다** — SEO도 애드센스도 아니고, **본문이 독자에게 없는 것을 가리키고 있다**는 사실 하나다.

### 3-1. 마케팅팀 명분 검증 — 표의 SEO 효과는 0으로 잡아야 한다

어제 브레드크럼 때와 같은 회의주의를 요구했고, 같은 결과가 나왔다.

- **"표를 넣으면 애드센스 재심사에 유리하다"** → 1차 출처 **0건**. "unique content" 요건에 대한 **2단계 추론**이다.
- **"표는 피처드 스니펫에 유리하다"** → 1차 출처 **0건**. 구글 공식 문구는 오히려 **"You can't"**(스니펫 지정 마크업 불가). 널리 복제되지만 원출처가 없는 업계 통설이다.
- **⚠️ 역효과 시나리오**: "템플릿 반복이 원인"이라는 우리 가설이 맞다면, **36개 글에 같은 모양의 표를 일괄 삽입하는 것은 반복을 오히려 강화한다.** 표가 도움이 되는 유일한 조건은 내용이 글마다 실제로 다를 때다. → 오늘 넣은 2개는 서로 완전히 다른 데이터(체중 범위 / 연차 일수)이고, **일괄 삽입을 하지 않은 것이 옳다.**

### 3-2. 🔴 마케팅팀 신규 P0 — 결함 클래스가 더 넓다

같은 유니온 결함의 피해자가 표·이미지만이 아니었다.

### 7-1. ★FAIL-1 수용 — 내 스코프 결정이 만든 결함, 되돌렸다

**마스터 판정: QA가 옳다. DSR 전환을 원복했다.**

②를 표로 올리는 선택지도 검토했으나 데이터가 **4개 축**(금리 · 월 상환액 · 연 원리금 · DSR+구간)이라 **오늘 내가 정본화한 3열 상한 안에서 무손실 전환이 불가능**하다. 열을 줄이면 라이브 값 6개가 사라지고, 4열로 가면 **몇 시간 전에 내가 만든 규범을 스스로 깬다.** 둘 다 수용 불가 → 원복이 유일하게 일관된 선택이다.

**결과: 발행 3개 → 2개.** 표를 못 넣어서가 아니라 **넣으면 본문과 어긋나기 때문**에 뺐다.

### 7-2. FAIL-3·관찰 1 수용 — 마스터가 직접 정정

### 7-3. 수용하되 이번 라운드에 고치지 않은 것

- **FAIL-2(연차 글 산문 부정확)**: `"이 글의 모든 표는…"`(실제로는 표 1 + 리스트 3), `"이 표에서 16일 줄"`(직전 블록은 리스트). **변경 전에도 틀려 있었고 내 회귀가 아니다.** 같은 클래스 결함이 **15개 글에 남아 있어** 개별 땜질이 아니라 일괄 라운드가 맞다 → 티켓 #24.
- **읽는 시간 12분 → 11분**(연차 글, 카드가 노출되는 **8개 페이지**에 파급). QA가 직접 검산해 **반올림 경계 아티팩트**임을 확인했다: 글자수 5,753 → 5,728(**-25자**), 경계는 5,750. 감소분은 리스트 구분자 `" → "`가 열 분리로 대체되며 사라진 것으로 **콘텐츠 손실이 아니다.** 조치하지 않고 기록만 한다.
  > 개발팀 보고는 해당 글 1개만 언급했고 **8개 페이지 파급을 빠뜨렸다.** 결함은 아니지만 보고 누락이며, QA의 전수 대조가 잡았다.
