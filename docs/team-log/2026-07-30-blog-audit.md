### 🔴 F-1 · `lib/blog.ts:5671` — 수치와 괄호 라벨이 서로 다른 구간을 가리킴 (자기모순)

| 유형 | **③ 자기모순** (같은 글 안 표와 정면 충돌) |
| 라이브 | **노출 중** — `.next/server/app/blog/electricity-usage-marginal-cost-2026.html` |

**본문 원문**
```
"3단계에 있다면 절약 효과가 가장 큼 — 100kWh를 줄이면 약 36,200원이 줄어듦(500kWh → 400kWh 구간)"
```

| | 값 |
| --- | --- |
| 본문 주장 | 500kWh → 400kWh 구간 = **36,200원** |
| 실측(엔진) | 500kWh → 400kWh = **37,420원** / 600kWh → 500kWh = **36,200원** |

**같은 글의 §"같은 100kWh인데" 표가 이미 반대로 적고 있다**:
- `L5521` `"[한계] 400kWh → 500kWh: 72,860원 → 110,280원, 37,420원 증가"`
- `L5523` `"[한계] 500kWh → 600kWh: 110,280원 → 146,480원, 36,200원 증가"`

즉 `36,200`은 **600↔500 구간의 값**인데 요약 팁에서는 **500↔400 라벨**에 붙었다.
독자가 500kWh에서 100kWh를 줄이면 실제로는 37,420원이 절약되므로, 본문은 절약효과를 **1,220원 과소** 안내한다.

**재현**
```ts
// scratchpad/batch5.mts
const tot = (u) => calculateElectricity({ usage: u, season: "summer" }).result.total;
tot(500) - tot(400) // 110,280 - 72,860 = 37,420
tot(600) - tot(500) // 146,480 - 110,280 = 36,200
```
**수정 방향(dev 판단)**: 라벨을 `(600kWh → 500kWh 구간)`으로 바꾸거나, 수치를 `37,420원`으로 바꾼다.
둘 중 어느 쪽이든 `L5521`/`L5523` 표와 반드시 대조할 것.

#### ★ 티켓 전제 정정 (중요 — dev가 잘못 고치면 회귀)
인계문에는 *"`≈ 8,812,388원` → 실측 **8,812,380**"* 이라 적혀 있으나, **이는 좌변을 축자 계산한 값**이다.

**수정 방향(dev 판단)**: 좌변을 정밀식으로 교체 — 예 `"퇴직금: 9,000,000 ÷ 92 × 30 × 1,096 ÷ 365 ≈ 8,812,388원"`.

### ⚪ A-1 · `lib/blog.ts:2475` — 괄호 안 등식이 오독 가능
```
"⑤ 연간 상여 1,200만원 추가: 임금총액 12,000,000원(9,000,000 + 1,200만 × 3/12 = 300만 증가) · …"
```
`= 300만 증가`는 **`1,200만 × 3/12`에만** 걸리는데, 표기상 `9,000,000 + 3,000,000 = 300만`으로 읽힐 여지가 있다.
수치 자체는 전부 정확(9,000,000 + 3,000,000 = 12,000,000 ✓ / 1일 평균임금 130,435 ✓ / 퇴직금 11,749,851 = 엔진값 ✓).
자동 검산기가 이 줄을 불일치로 뱉은 것도 같은 이유다. 표현만 다듬으면 된다.
